# SHO Questions

Interactive NIOSH Malaysia SHO Module 1 legislation practice quiz.

## Pages

- [`landing.html`](landing.html) — topic-based landing page and practice launcher.
- [`index.html`](index.html) — full interactive quiz.
- `landing.css` and `landing.js` — landing page styles and topic-selection behavior.

The landing page links to the existing quiz and can filter it by topic. The quiz remains self-contained in `index.html` so the existing questions and scoring behavior stay intact.

> Peer practice resource. Refer to current legislation and official NIOSH materials for authoritative guidance.
